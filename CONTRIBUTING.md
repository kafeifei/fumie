# Contributing to Fumie

Fumie is a personal research project. Focused fixes and reproducible reports
are welcome. Explain the observed behavior, the change, and how it was checked.

See [Development](docs/development.md) for build and test commands and
[Architecture](docs/architecture.md) for the code map. Keep provider-specific
behavior in adapters and preserve upstream attribution.

Use the repository's issues and pull requests for public discussion. Remove
credentials, private endpoints, personal paths, and sensitive session content
from examples and attachments. Report security issues privately as described
in [Security](SECURITY.md).
